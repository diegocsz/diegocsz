# Hola, ¡Soy Diego! 👋

Me llamo Diego Salcedo, tengo 19 años y soy estudiante de Ingeniería de Software en la Universidad Tecnológica del Perú (UTP).

Mi enfoque profesional es convertirme en un **Glue Engineer**: el ingeniero que domina la franja entre el hardware de bajo nivel y el software moderno de alto rendimiento. Mi objetivo es conectar el mundo físico con la nube, utilizando tecnologías que no solo funcionan, sino que son elegantes y escalables.

### 🛠 Mi Stack Tecnológico

* **Lenguajes:** Kotlin (Mi lenguaje principal), C++ Moderno (C++20/23) y Python.
* **Ecosistema:** Jetpack Compose, Kotlin Multiplatform (KMP), JVM.
* **IDEs de JetBrains:** IntelliJ IDEA (Backend/JVM), PyCharm (Python), Android Studio (Compose/Mobile) y CLion (C++ moderno).
* **Infraestructura:** Google Cloud Platform (GCP) para telemetría y backends en la nube.
* **Hardware:** Arquitectura ARM y sistemas integrados.

### 🚀 Mi Ruta Maestra (Roadmap)

Estoy ejecutando un plan de 4 fases para dominar el stack completo:

1. **Bases de Acero:** Consolidando lógica avanzada con *CS50 (Harvard)* y Python.
2. **Límite Inferior:** Dominio de C++ Moderno y arquitectura ARM para interactuar con hardware de forma eficiente.
3. **El Pegamento (JVM & Cloud):** Backend robusto con Kotlin (Ktor) y despliegue en GCP (Cloud Run).
4. **Capa Visual:** Interfaces modernas con Jetpack Compose y despliegue multiplataforma con KMP.

### 🎯 Proyecto Integrador: "The Showstopper"

Estoy construyendo un sistema de punta a punta:

* **Físico:** Simulaciones y dispositivos (como mi proyecto *pendulo-doble*) procesados en C++.
* **Enlace:** Backend en Kotlin recibiendo y estructurando datos en la nube.
* **UI:** Aplicación nativa con Jetpack Compose para visualización en tiempo real.
