
# Hola, ¡Soy Diego! 👋

Me llamo Diego Salcedo, tengo 19 años y soy estudiante de Ingeniería de Software en la Universidad Tecnológica del Perú (UTP).

Mi enfoque profesional se centra en dominar la intersección entre el hardware de bajo nivel y el software de alto rendimiento. Mi objetivo es construir sistemas integrados que conecten el mundo físico con la nube de forma elegante y escalable, explorando cómo un lenguaje moderno como Kotlin puede trascender su rol tradicional para integrarse profundamente tanto en la infraestructura como en herramientas de sistema.

### 🛠 Mi Stack Tecnológico

* **Lenguajes:** Kotlin (Eje central y principal), C++ Moderno (C++20/23, con visión a futuro hacia Carbon Lang) y Python.
* **Ecosistema:** Kotlin/Native, Kotlin Multiplatform (KMP), Jetpack Compose y JVM.
* **IDEs de JetBrains:** IntelliJ IDEA (Backend/JVM), PyCharm (Python), Android Studio (Compose/Mobile) y CLion (C++ moderno).
* **Infraestructura:** Google Cloud Platform (GCP) para telemetría y backends en la nube.
* **Hardware y Sistemas:** Arquitectura ARM, sistemas integrados y experimentación con arquitecturas modulares (como AOSP).

### 🚀 Mi Ruta Maestra (Roadmap)

Estoy ejecutando un plan de 4 fases para dominar el stack completo:

1. **Bases de Acero:** Consolidando lógica avanzada con *CS50 (Harvard)* y Python *Code In Place (Stanford)*.
2. **Límite Inferior:** Dominio de C++ Moderno, interoperabilidad nativa y arquitectura ARM para interactuar con hardware de forma eficiente.
3. **El Puente (JVM & Cloud):** Backend robusto con Kotlin (Ktor) y despliegue en GCP (Cloud Run).
4. **Capa Visual y de Control:** Interfaces modernas con Jetpack Compose y despliegue multiplataforma con KMP.

### 🎯 Proyecto Integrador: "The Showstopper"

Estoy construyendo un sistema de punta a punta:

* **Físico y Simulación:** Procesamiento de dispositivos y simulaciones (como mi proyecto *pendulo-doble*) ejecutados en C++ moderno.
* **Enlace y Procesamiento:** Backend en Kotlin recibiendo, estructurando y gestionando datos en la nube.
* **UI de Control:** Aplicación nativa con Jetpack Compose para visualización y monitoreo en tiempo real.
